Install your Harvora email signature

Takes about a minute. Do it on desktop Gmail — the mobile app can’t paste formatting.

  1. Click Copy signature under your name below.
  2. In Gmail, open Settings (gear icon) → See all settings.
  3. Scroll to Signature → Create new → name it Harvora.
  4. Click into the editing box and paste (⌘V / Ctrl+V).
  5. Under Signature defaults, set both dropdowns to Harvora.
  6. Tick Insert signature before the quoted text in replies, then Save Changes at the bottom.
